# Spatially Context-Aware Multilevel Color Image Segmentation

This repository contains the MATLAB implementation of the proposed spatially context-aware multilevel color image segmentation method using a hybrid Artificial Hummingbird Algorithm and Great Deluge mechanism.

## Code Availability

The custom MATLAB code used to generate the results reported in the manuscript is provided in this repository. The datasets used in the study are publicly available and are not redistributed here. Users should download the BSDS500 and NASA Earth Observatory images from their original sources and place them in the input image folder before running the code.

## Requirements

- MATLAB
- Image Processing Toolbox

## How to Run

1. Download the publicly available dataset images.
2. Place the input images in the required input folder.
3. Open MATLAB.
4. Set this repository folder as the current working directory.
5. Run `main.m`.
